# Basketball Shot Chart

Локальное веб-приложение для записи и анализа баскетбольных бросков. Позволяет создавать тренировки, отмечать попадания и промахи на интерактивной площадке, отслеживать статистику по зонам и получать рекомендации после завершения тренировки.

## Возможности

- создание и сохранение тренировок;
- интерактивная карта баскетбольной площадки;
- отметка попаданий и промахов;
- отмена последнего броска;
- подсчёт общего количества бросков;
- расчёт количества попаданий и промахов;
- автоматический расчёт FG%;
- статистика по сторонам и дистанциям;
- история тренировок;
- итоговый анализ сильных и слабых зон;
- рекомендации упражнений;
- адаптивный интерфейс для компьютеров, планшетов и телефонов;
- локальное хранение данных без сервера.

## Анализ бросков

Площадка условно разделяется по сторонам:

- левая;
- центральная;
- правая.

Также учитывается дистанция:

- бросок из-под кольца;
- средняя дистанция;
- трёхочковый бросок.

В результате формируются девять возможных зон:

```text
Слева · Под кольцом
Слева · Средняя дистанция
Слева · Трёхочковый

По центру · Под кольцом
По центру · Средняя дистанция
По центру · Трёхочковый

Справа · Под кольцом
Справа · Средняя дистанция
Справа · Трёхочковый
```

После завершения тренировки приложение:

1. рассчитывает общую точность;
2. определяет наиболее сильную зону;
3. определяет зону с наименьшей точностью;
4. показывает количество попаданий и попыток;
5. предлагает упражнения для следующей тренировки.

## Как пользоваться

1. Введите название тренировки.
2. Выберите дату.
3. При необходимости добавьте заметку.
4. Нажмите **«Создать тренировку»**.
5. Выберите результат броска:
   - попадание;
   - промах.
6. Нажмите на место броска на площадке.
7. Следите за обновлением статистики.
8. Нажмите **«Завершить тренировку»**.
9. Подтвердите завершение во встроенном окне.
10. Изучите итоговый анализ и рекомендации.

Завершённую тренировку можно открыть из истории и повторно посмотреть её анализ.

## Хранение данных

Все тренировки и броски сохраняются в `localStorage` браузера.

Это означает, что данные:

- сохраняются после обновления страницы;
- сохраняются после закрытия браузера;
- доступны только в том браузере, где были созданы;
- не синхронизируются между устройствами;
- могут быть удалены при очистке данных сайта.

При открытии приложения через другой адрес браузер может создать отдельное хранилище. Например, данные на `127.0.0.1` и на GitHub Pages хранятся независимо.

## Адаптивность

Интерфейс адаптирован для:

- настольных компьютеров;
- ноутбуков;
- планшетов;
- телефонов;
- горизонтальной ориентации телефона или планшета.

На небольших экранах панели перестраиваются в одну колонку, а площадка и модальные окна автоматически подстраиваются под доступную ширину.

## Ограничения

- данные не синхронизируются между устройствами;
- приложение не использует регистрацию пользователей;
- анализ строится только на основе отмеченных бросков;
- при небольшом количестве попыток точность по зонам может быть недостаточно показательной;
- очистка данных браузера удаляет сохранённую историю.
